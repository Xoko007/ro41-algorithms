Отчет по заданию: Ручная трассировка алгоритмов

Алгоритм А (Факториал при n = 5)
Инициализация: f = 1, n = 5
Итерация 1: i = 1, f = 1 * 1 = 1, n = 5
Итерация 2: i = 2, f = 1 * 2 = 2, n = 5
Итерация 3: i = 3, f = 2 * 3 = 6, n = 5
Итерация 4: i = 4, f = 6 * 4 = 24, n = 5
Итерация 5: i = 5, f = 24 * 5 = 120, n = 5
Результат работы алгоритма А: 120
