# Отчет по СРС 6: Трассировка массивов

Исходный массив: a = {4, 1, 7, 3, 9}, размер n = 5.

## 1. Трассировка циклического сдвига влево на одну позицию

Алгоритм:
1. Сохранение первого элемента в буфер: buffer = a[0] (4).
2. Цикл сдвига элементов влево от i = 0 до n - 2: a[i] = a[i + 1].
3. Запись значения из буфера в конец массива: a[n - 1] = buffer.

| Шаг | Индекс i | Операция | Состояние массива a |
| :---: | :---: | :--- | :--- |
| **Инициализация** | — | buffer = a[0] (buffer = 4) | {4, 1, 7, 3, 9} |
| **Шаг 1** | 0 | a[0] = a[1] (1) | {1, 1, 7, 3, 9} |
| **Шаг 2** | 1 | a[1] = a[2] (7) | {1, 7, 7, 3, 9} |
| **Шаг 3** | 2 | a[2] = a[3] (3) | {1, 7, 3, 3, 9} |
| **Шаг 4** | 3 | a[3] = a[4] (9) | {1, 7, 3, 9, 9} |
| **Финал** | — | a[4] = buffer (4) | {1, 7, 3, 9, 4} |

---

## 2. Разворот массива на месте

* **Количество выполненных обменов:** 2 обмена (при i = 0 и i = 1).
* **Почему цикл идёт только до n / 2 (5 / 2 = 2):** 
  Если выполнять цикл до конца массива (n), то во второй половине элементы будут повторно поменяны местами и вернутся в исходное положение (разворот отменится). При нечетном размере массива средний элемент (a[2] = 7) остался бы на своем месте, а обмен его с самим собой избыточен.

**Пошаговый процесс обменов:**
* i = 0: обмен a[0] (4) и a[4] (9) -> массив: {9, 1, 7, 3, 4}
* i = 1: обмен a[1] (1) и a[3] (3) -> массив: {9, 3, 7, 1, 4}

---

## 3. Анализ алгоритма поиска минимума с начальным значением min = 0

* **Ошибка:** Если переменная min хранит значение минимального элемента и инициализируется нулем (min = 0), алгоритм дает сбой на массивах, состоящих исключительно из положительных чисел (где все элементы больше нуля).
* **Контрпример:** Массив a = {5, 8, 12}.
  * Условие поиска if (a[i] < min) для каждого элемента (5 < 0, 8 < 0, 12 < 0) вернет false.
  * В результате алгоритм ошибочно вернет 0, хотя такого числа в массиве нет.
* **Исправление:** Инициализировать min первым элементом массива:

  int min = a[0]; // корректная инициализация значением первого элемента
