# Отчет по СРС 5: Трассировка рекурсивной функции

## 1. Базовый случай и шаг рекурсии

* **Базовый случай (Base Case):** 
  `if (n <= 1) return 1;`
  *Объяснение:* Это условие остановки рекурсии. Когда значение параметра `n` достигает $1$ или меньше, функция прекращает вызывать саму себя и возвращает фиксированное значение $1$, предотвращая бесконечный цикл.

* **Шаг рекурсии (Recursive Step):** 
  `return n * F(n - 1);`
  *Объяснение:* На каждом шаге задача сводится к более простой подзадаче: вычислению функции для аргумента, уменьшенного на единицу (`n - 1`), с последующим умножением результата на текущее `n`.

---

## 2. Ручная трассировка функции `F(4)`

Ниже представлена таблица пошагового выполнения вызова `F(4)`, отображающая погружение в стек вызовов (спуск) и возвращаемые значения (подъем).

| Вызов | Глубина стека | Описание / Вычисление | Возвращает |
| :--- | :---: | :--- | :---: |
| `F(4)` | 0 | `4 * F(3)` $\rightarrow$ ждет результат `F(3)` | **24** |
| `F(3)` | 1 | `3 * F(2)` $\rightarrow$ ждет результат `F(2)` | **6** |
| `F(2)` | 2 | `2 * F(1)` $\rightarrow$ ждет результат `F(1)` | **2** |
| `F(1)` | 3 | Базовый случай (`n <= 1`), условие истинно | **1** |

*Ход возврата значений вверх по стеку:*
1. `F(1)` возвращает `1`.
2. `F(2)` возвращает `2 * 1 = 2`.
3. `F(3)` возвращает `3 * 2 = 6`.
4. `F(4)` возвращает `4 * 6 = 24`.

## 3. Анализ некорректного условия для `F(-1)`

Если условие выхода заменить с `n <= 1` на **`n == 1`** и вызвать функцию **`F(-1)`**, произойдет следующее:

1. **Причина:** Проверка `n == 1` для начального аргумента `-1` дает ложь. Функция вызывает `F(-2)`, затем `F(-3)`, `F(-4)` и так далее. Поскольку аргумент с каждым шагом уменьшается (`-1, -2, -3...`), он удаляется от целевого значения `1`.
2. **Результат:** Возникает **бесконечная рекурсия**.
3. **Тип ошибки:** Происходит исчерпание памяти выделенного под стек потока, что приводит к критической системной ошибке **`StackOverflowException`** (переполнение стека вызовов).
