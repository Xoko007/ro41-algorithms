## 1. Трассировка сортировки выбором (Selection Sort)
**Исходный массив:** $a = \{5, 2, 9, 1, 7\}$ ($n = 5$)

Алгоритм на каждом шаге $i$ ищет минимальный элемент в неотсортированной части от $i$ до $n-1$ и меняет его местами с $a[i]$.

| Проход ($i$) | Индекс минимума | Массив после обмена | Число сравнений на проходе |
| :---: | :---: | :---: | :---: |
| 0 | 3 | `{1, 2, 9, 5, 7}` | 4 |
| 1 | 1 | `{1, 2, 9, 5, 7}` | 3 |
| 2 | 3 | `{1, 2, 5, 9, 7}` | 2 |
| 3 | 4 | `{1, 2, 5, 7, 9}` | 1 |

* **Общее число сравнений:** $4 + 3 + 2 + 1 = 10$.

## 2. Трассировка сортировки вставками (Insertion Sort)
**Исходный массив:** $a = {4, 3, 2, 1}$

| Шаг ($i$) | `key` ($a[i]$) | Число сдвигов | Массив после вставки |
| :---: | :---: | :---: | :---: |
| 1 | 3 | 1 | `{3, 4, 2, 1}` |
| 2 | 2 | 2 | `{2, 3, 4, 1}` |
| 3 | 1 | 3 | `{1, 2, 3, 4}` |

* **Сколько всего сдвигов:** $1 + 2 + 3 = 6$.
* **Сколько сравнений выполнит алгоритм на уже отсортированном массиве из 4 элементов:** **3 сравнения** (на каждом из $n-1$ шагов выполняется ровно 1 сравнение).

## 3. Трассировка бинарного поиска (Binary Search)
**Исходный массив:** `{1, 3, 5, 7, 9, 11, 13}`

### А. Поиск для $x = 7$
| Шаг | `lo` | `hi` | `mid` | `a[mid]` | Решение / Условие |
| :---: | :---: | :---: | :---: | :---: | :--- |
| 1 | 0 | 6 | 3 | 7 | `a[mid] == x` ($7 == 7$) — элемент найден на индексе `3`. |

### Б. Поиск для $x = 6$
| Шаг | `lo` | `hi` | `mid` | `a[mid]` | Решение / Условие |
| :---: | :---: | :---: | :---: | :---: | :--- |
| 1 | 0 | 6 | 3 | 7 | `a[mid] > x` ($7 > 6$) $\rightarrow$ `hi = mid - 1` ($2$). |
| 2 | 0 | 2 | 1 | 3 | `a[mid] < x` ($3 < 6$) $\rightarrow$ `lo = mid + 1` ($2$). |
| 3 | 2 | 2 | 2 | 5 | `a[mid] < x` ($5 < 6$) $\rightarrow$ `lo = mid + 1` ($3$). |

* **Чем закончится поиск:** Цикл завершится неудачно, так как условие `lo <= hi` ($3 \le 2$) становится ложным (элемент в массиве отсутствует).
* **Какое значение вернет `LowerBound(6)`:** Функция `LowerBound(6)` вернет индекс **`3`** (позиция первого элемента, который больше или равен $6$, то есть числа `7`).
