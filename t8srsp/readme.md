##  Описание проекта
Проект содержит статический класс `TextTools` с базовыми методами для обработки строк на языке C#. 
* **Ограничения:** Использование `Regex` и `Linq` запрещено.
* Пустые строки и строки, состоящие только из пробелов, обрабатываются корректно без выброса исключений.

---

##  Реализованные методы (`TextTools`)

1. **`CountWords(string s)`**  
   * Подсчитывает количество слов в строке. Лишние пробелы и знаки табуляции не влияют на результат.
2. **`IsPalindrome(string s)`**  
   * Проверяет, является ли строка палиндромом без учёта регистра, пробелов и знаков препинания.
3. **`Initials(string fullName)`**  
   * Преобразует полное имя (например, `"Ахметов Ерлан Серикұлы"`) в сокращенный вид с инициалами (`"А. Е. С."`).
4. **`Repeat(string s, int n)`**  
   * Повторяет переданную строку $n$ раз с использованием эффективного класса `StringBuilder`.

---

##  Тестирование и проверка
В методе `Main` реализованы проверки для следующих строк и кейсов:
* Пустая строка (`""`)
* Строка из пробелов (`"    "`)
* Строка с лишними пробелами (`" a   b "`)
* Проверка палиндрома (`"А роза упала на лапу Азора"`)
* Формирование инициалов (`"Ахметов Ерлан"`)
